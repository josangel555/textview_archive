### perf Fix#1 detail (TSK-108) — the big one
Tab-switch freeze was view-side: switching tore down + reloaded the inactive pane's `WKWebView`.
Now inactive panes stay mounted in a `ZStack`, retained by `MountedPanesLRU` (cap 4), at
**`.opacity(0)` + `.allowsHitTesting(false)` + `accessibilityHidden(true)` — NOT `.hidden()`**
(`.hidden()` makes WebKit fire `visibilitychange` and self-reload, the cmux #1228 pathology).
- `Sources/ViewerUI/DocumentModel.swift`: `@Published mountedPanes`, `mountedTabs`,
  `noteActiveTabForRetention()` (called at end of `updateDerived()`; epsilon-guarded write).
- `Sources/ViewerUI/ContentView.swift`: `content` = ZStack over `model.mountedTabs`; per-tab
  `tabContent(for:isActive:)`; find bar/query gated on `isActive`.
- `Sources/ViewerUI/MountProbe.swift` (`#if DEBUG`): counts web-view make/dismantle. Invariant:
  A→B→A = **0** new mounts; eviction past LRU cap = **1** dismantle. Asserted by
  `Tests/ViewerUITests/PaneRetentionMountProbeTests.swift` (webview lane) +
  `MountedPanesWiringTests.swift` (bare gate). Validated headless gate + live T4 smoke.

1. **`killall <name>` kills the owner's app** — installed app + test spawn share the exec name
   `MarkdownViewer`. The frequent trigger was `build-app.sh debug` → T4 ViewModeMatrix → `AppLauncher`.
   Fixed in `AppLauncher` (env marker + `killTestInstances`). **Remaining bare-`killall` sites to
   migrate the same way:** `SourceViewVisualRegressionTests`, `WalkthroughAndCodeReviewUATTests`,
   `LaunchHarness` (~:104). **Until those are migrated, be cautious running heavy/live tiers while
   the owner has the app open.** The headless gate itself (`test-headless-gate.sh`) does NOT spawn
   the app (heavy tiers self-skip) — it was `build-app.sh debug` that did.
2. **VM builds now** (TSK-401). VM = stricter Swift 6.1.2 on actor isolation, not broken. Fix
   patterns: `nonisolated(unsafe) let strongSelf = self` (NOT `[weak self]`) for "sending self" in
   `Task.detached`/`DispatchQueue.main.sync` bodies, then `MainActor.assumeIsolated { strongSelf.… }`;
   `nonisolated(unsafe) static let` for global locks. (`assumeIsolated` alone didn't clear it.)
3. **Flaky parallel gate** — a gate exit-1 with NO assertion text + a clean "tier enforcement OK"
   line = flaky parallel test, not your diff. Re-run once before chasing it.
4. **`TSK-NNN` (board) ≠ `#N` (Claude TaskList)** — numbering spaces collide; board is SoR, the CC
   TaskList is a stale mirror. And the board is **shared across projects** — TSK-101..106 are
   `agent:forge` (other project); grep this repo before acting on a board task.

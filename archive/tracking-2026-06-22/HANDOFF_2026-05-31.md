**Locked decisions for the (deferred) Rust core** — recorded in memory
(`project_rust_core_decision.md`) + `archive/RUST_CORE_PLAYBOOK_2026-05-30.md`:
- **Rust core** is the chosen direction. Sync, sans-IO functional core.
- **FFI = hand-rolled `extern "C"` + `cbindgen`, separate crate** (NOT uniffi/
  swift-bridge). Doc text crosses by opaque handle, never by value.
- **Crash reporting = DIY**, **telemetry = DIY**, **no large-file editing now
  (ropey later)**.
- **Adopt** (DIY = false economy): tree-sitter, comrak (`default-features=false`!),
  notify, tracing, serde, rustls. **Roll our own**: sync reducer, wire framing,
  RPC dispatch, level-triggered push engine, errors, channels.
- **Wire = `rmp-serde` (MessagePack)** for the cross-language tier;
  **`postcard` DROPPED** (heapless bloat, not lean for a host). DIY the framing.
- Dep blast-radius + bundle sizing measured: `archive/RUST_DEPENDENCY_AND_SIZING_2026-05-31.md`.
  TL;DR: Rust code is tiny (~0.5–3 MB); size = tree-sitter grammars (16 MB) +
  CM6/mermaid JS (4.2 MB), shared/shed per front-end. macOS app stays ~36 MB;
  TUI ~2–20 MB; WASM core sub-MB + 4.2 MB JS.

## What this project is

- macOS-native document viewer / minimal editor: `MarkdownViewer.app` (Finder name: `TextView.app`).
- Bundle id: `com.markdownviewer.MarkdownViewer` — **TCC-stable, do not change**.
- Swift 6 + SwiftUI + AppKit + WKWebView. macOS 15+.
- Read-only viewer for most modes; CodeMirror 6 in WKWebView powers an opt-in editable **Editor** mode for plain-text files.
- LSP integration (Swift via sourcekit-lsp; TS/JS/Java/Python via PATH-discovered servers).
- 14 TreeSitter grammars via lazy-loaded dylibs.
- Sessions = workspace persistence (folder root + tabs + zoom + word-wrap + theme per session).
- Local signing only (`MarkdownViewer Local Dev`); no Developer ID until shipping.

## Key patterns to know

### Coordinator pattern (DocumentModel split)

DocumentModel was a 2377-LOC, 71-`@Published`, 107-method god object. Split into:
- `FindCoordinator` — all three find-mode bags (rendered / source / editor)
- `TabCoordinator` — tabs, selectedIndex, open/close family, 6 per-tab dicts
- `EditorCoordinator` — editor mode, ⌘S, dirty, close prompt, conflict, cursor/scroll, diagnostics fan-out

**Pattern shape:**
- Each coordinator is `@MainActor` + `ObservableObject`
- Stored on DocumentModel as `public let find / tabs / editor: …Coordinator`
- **Forwarders preserved on DocumentModel** — every public API you moved gets a thin wrapper so call sites compile unchanged
- **Republish-invariant tests** pin the contract: mutating a coordinator field fires `objectWillChange` on the coordinator only, never on DocumentModel. Pattern: `Tests/ViewerUITests/*RepublishInvariantTests.swift`. The `countDocumentRepublishes(while:)` helper is in `TabRepublishInvariantTests.swift`.

### `TabCoordinator.addCloseHook(_:)`

Single fan-out point for per-tab subsystem cleanup. EditorCoordinator registers via `tabs.addCloseHook { id in self.cleanup(id) }`. Future coordinators owning per-tab state should use the same hook — **don't add another close-path enumeration**.

### CM6 bridge protocol (versioned)

- **JS host:** `Sources/ViewerUI/Resources/codemirror/codemirror.html` — single `window.cmDispatch({...})` switch over message types
- **Swift codec:** `Sources/ViewerCore/CodeMirrorBridgeV1.swift` — typed `CMInboundMessage` + `CMOutboundMessage` + `CMBridgeCodec` JSON
- **Envelope:** `{v: 1|2, type: "…", replyId?: int, …}`. Unknown types decode to `.unknown` (forward-compat).
- **v2 added** `incrementalChange` (inbound) + `applyEdits` / `setFoldingRanges` / `setGutterMarkers` / `setIndentGuides` (outbound). v1 path preserved one cycle.
- **Edit applier:** `Sources/ViewerCore/CMEditApplier.swift` — UTF-16 indexed, rejects overlap/OOB; on length-drift Swift requests `flushChanges` v1 fallback.
- **Bundle build:** `scripts/codemirror-build/` — `npm install --no-audit --no-fund && npm run build` writes `Sources/ViewerUI/Resources/codemirror/codemirror.js`. **No `node_modules` in runtime app.**
- **JS-safe JSON:** all bridge calls route through `Sources/ViewerCore/JSStringEmbedding.sanitize` (handles U+2028/2029).

### `HighlightCacheActor` per-tab

`Sources/ViewerUI/Highlight/HighlightCacheActor.swift`. One actor per tab. Owned by DocumentModel in a non-`@Published` `[UUID: HighlightCacheActor]` dict. Narrow republish channel = `@Published var version: Int` on the actor. `SourceModeView` observes the actor directly, so highlight-ready re-evals only that subtree. Per-tab cap 8 (was 32 global).

### Rendered-HTML cache key

`RenderedHTMLKey = (tabID, byteCount, modifiedTime)`. `modifiedTime` plumbed through `TextFileLoader.load` (all encoding paths) + re-stats on save. Replaced an FNV hash that was firing per body re-eval.

### Sidebar republish chain — severed

`DocumentModel` **no longer** forwards `SidebarModel.objectWillChange`. Every view that needs sidebar state holds its own `@ObservedObject sidebar`. `SidebarRepublishInvariantTests` pins this; mutating sidebar fields must not fire `DocumentModel.objectWillChange`. The negative-control test inside that file catches "publisher silently disabled."

### `SidebarSectionPlanner`

`Sources/ViewerCore/SidebarSectionPlanner.swift` — pure-logic helper that takes `[(panel, isVisible)]` and emits visible panels with `drawTrailingDivider` flag. Fixes "bunched divider lines under hidden panels."

### Security hardening (recent)

- `Sources/ViewerCore/Security/URLSchemePolicy.swift` — `markdownviewer://open?path=…` containment ($HOME + $TMPDIR only)
- `Sources/ViewerCore/Security/RegexComplexityGuard.swift` — `FindEngine` + MCP `find` regex DoS guard
- `Sources/ViewerCore/HTMLSanitizer.swift` — allowlist; CSP becomes defense-in-depth
- Walkthrough drop transport requires `TV_WALKTHROUGH_DROP=1` env var
- `EditorWriter.save` refuses symlinks unless `allowSymlink: true` opt-in
- `LSPDiscovery` refuses group/world-writable bin dirs

### Process subprocess pattern — `ProcessRunner`

`Sources/ViewerCore/ProcessRunner.swift` — extracted helper for `Process` + drain. `GitClient`, `JQRunner`, `PluginSubprocessHost`, `LSPDiscovery` all migrated. `GitService` deleted (merged into `GitClient`).

### FakeLSPServer

`Sources/MDVFakeLSPServer/main.swift` — exec target for host-runnable LSP tests. Env-driven scenarios: `normal | fail_initialize | slow_init | crash_after_init | garbled_after_init | encoding_utf8 | publishDiagnostics | hoverDelayMs`. Helper at `Tests/ViewerCoreTests/LSP/FakeLSPServerHelper.swift` locates the binary via `Package.swift` walk. **Unblocked 15 host LSP tests** that were previously env-gated smoke (`MDV_RUN_LSP_SMOKE=1`).

## Test discipline

**CLAUDE.md rule:** anything that opens a window / starts NSApplication / spawns the `.app` belongs on the UTM VM. Pure logic stays on host.

**Host filter examples:**
- `swift test --filter ViewerCoreTests` — pure logic + integration that doesn't open windows
- `swift test --filter ViewerKitTests` — pure value types
- `swift test --filter ViewerUITests.<SuiteName>` — host-safe @MainActor coordinator/state-machine tests
- **Never** `swift test` unfiltered on host (will sweep VM-targeted tests that need real NSApplication).

**Test tiers:**
- **Unit** — pure logic, no I/O
- **Integration** — Swift state machine + real tmp files (`FileManager.default.temporaryDirectory`)
- **VM E2E** — `Tests/ViewerUITests/Editor/*ScenarioTests.swift` style, driven by script verbs via `AppLauncher.runScript`. Sweep on VM only.

**VM workflow:**
```
rsync -az --delete --exclude='.build/' --exclude='.swiftpm/' \
  --exclude='dist/' --exclude='.git/objects/pack/' \
  /Users/me/Documents/workspaces/claude/markdown_viewer/ \
  macOS15:markdown_viewer/
ssh macOS15 'cd markdown_viewer && swift test'
```
**VM creds:** host `macOS15`, user `vm-tester@<vm-ip>`, sudo `<vm-sudo-password>`. **Don't `git pull` on VM** — rsync mirror only.

**Republish-invariant pattern** for new coordinators:
```swift
func countDocumentRepublishes(while: () -> Void) -> Int { … }
// Then assert mutating coordinator field → 0 publishes
```
Adopt this for every observation chain change.

## Dispatching subagents (workflow patterns we've settled on)

**Generic prompts.** Per user's CLAUDE.md update + memory: hand over goal + constraints + coexistence notes, then **stop**. Don't pre-bake feature lists / file layouts / numbered scenarios for research/exploration agents. Reserve prescriptive prompts for focused mechanical fixes where the cause is known.

**Worktree isolation.** `isolation: "worktree"` for code-changing agents. Each agent lands on its own branch; orchestrator merges with `git fetch ./.claude/worktrees/agent-XXXX <branch>` then `git merge --no-ff FETCH_HEAD`.

**Commit-incrementally rule.** Tell agents to commit in flight, not at the end. Worktrees can be GC'd after completion; uncommitted work has been lost more than once. Surfaced as a recurring failure mode.

**Coexistence markers.** When two agents touch overlapping files, brief them with marker-comment conventions (`// MARK: - feature-X (agent-name)`) so merges are mechanical.

**Conflict triage:** when a working-tree edit blocks a merge, `git stash push -- <files>` → merge → `git stash pop` (then verify dedupe). Has happened ~3× this cycle.

**External rate limits:** agents can hit Anthropic rate limits mid-run. Worktree may or may not have partial commits. Always check the worktree dir before re-dispatching; resume the same agent via `SendMessage` when possible.

## Gotchas (learned the hard way)

- **CM6 peer-dep version floor:** bumping `@codemirror/view` without bumping `@codemirror/state` to its peer floor → silent duplicate module → `EditorState.create()` throws `instanceof` mismatch inside IIFE → **blank editor**, CSP swallows error. Fix: `cd scripts/codemirror-build && rm -rf node_modules package-lock.json && npm install && npm run build`; verify in `BUILD.md`.
- **`Data.subdata(in:)` after `removeFirst` on macOS 26**: slice offset isn't surfaced through `count`/`subdata` consistently. Rebuild via `[UInt8]` array. `LSPFraming.decode` defends with `Data(rawBuffer)`.
- **`FileHandle.read(upToCount:)` + `write(contentsOf:)` concurrent on same `Pipe` wedges writes after 1-2 messages.** Use raw POSIX `read(2)` / `write(2)` on fds. Caught by FakeLSPServer; was papered over by env-gated tests.
- **Blocking read on `Task.detached` starves cooperative pool** → `CancellationError` at unrelated `await` sites. Use dedicated `Thread`. Same incident as above.
- **`evaluateJavaScript` string-embed** breaks on U+2028 / U+2029 (line terminators in JS but not JSON). All bridge JSON now routes through `JSStringEmbedding.sanitize`.
- **`SIGPIPE` on stdin write end** crashes LSP host on clean child exit. `F_SETNOSIGPIPE` on the fd.
- **SwiftUI republish forwarding** (`child.objectWillChange → parent.objectWillChange`) amplifies every tick across every parent observer. Don't forward; use direct `@ObservedObject` on the child instead.
- **`@Published` on dictionary caches** republishes the whole `ObservableObject` on every cache write. Use actor + narrow `version: Int` instead.
- **`UserDefaults` writes during view-init** clobber persisted values with defaults. The Sessions tab persistence bug was this shape.
- **Worktree pruning** loses uncommitted work. Always `git commit` in flight.
- **CSP `style-src 'unsafe-inline'` is permitted** in recent WebKit — CSP is not a sufficient HTML-injection defense. `HTMLSanitizer` allowlist is the real fix.
- **Editor cursor/scroll/diagnostics dicts** leaked per-tab entries forever (no cleanup on close paths). Latent memory leak. Surfaced by EditorCoordinator extraction; fixed via `addCloseHook`.

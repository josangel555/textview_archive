# Security

This repository is an **archived source snapshot** of TextView and is not
maintained here. It receives no fixes, releases, or issue triage.

- Do not report vulnerabilities against this archive; it is a historical
  showcase of the codebase as of the snapshot date in `README.md`.
- Pre-built application bundles are published separately (see the download
  pointer in `README.md`); they are self-signed local-dev builds, not
  notarized, and are provided as-is.
- The automation surfaces in this codebase (the MCP socket, script verbs,
  plugin host) were designed for a single-user local developer workflow and
  assume a trusted local machine.

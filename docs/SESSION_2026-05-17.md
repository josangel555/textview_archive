  Wired into the tab right-click context menu as "Reveal in Sidebar".

  reveal-out-of-tree is a silent no-op.

  View menu → "Apply jq Filter… (⌥⌘J)". Prompts for a filter, runs

  concurrent pipe drain + 10 s timeout watchdog. 6 unit tests
  including a 200 KB no-deadlock case.
